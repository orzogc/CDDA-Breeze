# 模组角色立绘接口

微风的普通 NPC 对话界面支持“专属立绘、实时贴图预览、隐藏显示”三种角色卡显示方式。

推荐模组在 NPC 模板 JSON 中使用 `portrait` 指定稳定的立绘标识：

```json
{
  "type": "NPC",
  "id": "NPC_LIANG_ZHIYAO",
  "name_unique": "梁知遥",
  "portrait": "梁知遥"
}
```

图片放在：

`mods/你的模组/character_picture/梁知遥.png`

`portrait` 不写 `.png`。它可以与 NPC 的显示姓名不同，因此角色名字后缀、本地化文本或称呼变化不会影响立绘绑定。

读取和显示规则：

1. 有 `portrait` 且图片存在时，默认显示专属立绘。
2. 没有专属立绘，但当前贴图包可用时，默认实时绘制 NPC 当前全身外观，包括身体、衣物、武器和其他 overlay。
3. 没有任何可用图像资源时，显示“暂无立绘”。
4. 对话中按大写 `C` 可以循环切换：
   - 有专属立绘：专属立绘 → 实时预览 → 暂无立绘 → 专属立绘。
   - 无专属立绘：实时预览 → 暂无立绘 → 实时预览。
   - 当前贴图不可用时，会自动跳过实时预览状态。
5. 小写 `c` 仍然保留给普通对话选项，大写 `C` 不会抢占第三个回答。

专属立绘采用 cover 方式铺满角色卡，保持原始比例并裁掉少量多余边缘。推荐使用 3:4 近景胸像，1086×1448 或更高的同等比例图片，脸部、头发和肩部轮廓应在缩小后仍然清楚。

实时预览不会生成或保存截图文件，也不会一次性预加载大量人物图片，它直接复用当前贴图包和 NPC 当前 overlay。

## 对话角色卡信息

角色卡底部会显示 NPC 姓名、职业和好感度。好感度按“信任 × 2 + 价值 − 恐惧 × 2 − 愤怒 × 5”计算，并限制在 -100 到 100；负数显示为红色，0 显示为白色，正数显示为绿色。

对话中按 `O`（查看好感）可以查看各项数值和计算明细。按 `L` 观察 NPC 时，只会列出普通观察能够看见的外层服装；被外层服装完全遮挡的内衣不会直接显示。
