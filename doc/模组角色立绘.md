# 模组角色立绘接口，第一版

微风会在普通 NPC 对话开始时寻找角色立绘。第一版仍然使用角色的显示姓名作为文件名，以保持与现有 `gfx/character_picture` 立绘完全兼容。

模组可以在自己的根目录建立 `character_picture` 文件夹，并把立绘保存为 `角色显示姓名.png`。例如，一个模组目录为 `mods/MyMod`，角色在游戏里显示为 `李明`，则立绘路径为 `mods/MyMod/character_picture/李明.png`。

加载优先级为，后加载的启用模组，先加载的启用模组，游戏本体 `gfx/character_picture`，世界存档中的 NPC 动态立绘，AI 生成立绘。只检查当前世界已经启用的模组，因此没有启用的模组不会注入立绘。

推荐新立绘统一为 3 比 4 竖幅，推荐原图尺寸 768 乘 1024 像素。构图以胸像为主，完整保留头发和双肩。界面会保持原图纵横比缩放进左侧相框，因此旧版 381 乘 522 立绘也可以继续使用，不要求批量重做。

这一版没有加入独立的 `portrait_id` JSON 字段。换句话说，角色改名和同名角色仍然可能产生歧义。先用这一版验证界面和模组覆盖流程，后续再把稳定资源 ID 作为第二阶段接口加入。
