# 模组角色立绘接口

微风会在普通 NPC 对话开始时寻找角色立绘。推荐模组直接在 NPC 模板 JSON 中使用 `portrait` 指定稳定的立绘标识，不再把角色显示姓名当作唯一资源 ID。

模组在自己的根目录建立 `character_picture` 文件夹，并把立绘保存为 `立绘标识.png`。例如：

```json
{
  "type": "NPC",
  "id": "NPC_LIANG_ZHIYAO",
  "name_unique": "梁知遥",
  "portrait": "梁知遥"
}
```

对应图片放在：

`mods/你的模组/character_picture/梁知遥.png`

`portrait` 填写文件名去掉 `.png` 后的部分。它也可以与 NPC 的显示姓名完全不同，因此角色改名、本地化或出现同名 NPC 时不会影响立绘绑定。

读取顺序为：先读取 NPC JSON 明确指定的 `portrait`，在当前世界已经启用的模组中按后加载模组优先查找；若没有找到，再回退到旧的 `角色显示姓名.png` 兼容规则；之后继续使用游戏本体立绘、世界存档中的 NPC 动态立绘和 AI 生成立绘。没有启用的模组不会注入立绘。

当前对话 UI 更适合 3 比 4 的胸像立绘，推荐原图尺寸 1086 乘 1448 像素或更高的同等比例尺寸。构图建议为近景胸像：头部和双肩占画面主要面积，人物脸部尽量清晰，背景尽量干净。这样在缩小显示时会比完整插画更清楚，也更贴合卡面。

如果两个启用模组提供了相同 `portrait` 标识，后加载的模组优先，可用于兼容包或立绘替换包覆盖原立绘。
